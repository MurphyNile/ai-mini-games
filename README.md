# AI-Assisted Mini Games

A collection of small playable studies. This series uses AI-assisted prototyping to explore how rules, interfaces, and feedback shape what players notice and do.

- [The City Is On Time — One More Second](the-city-is-on-time/) explores who gets extra time at a city intersection.
- [Orbital Resonance](orbital-resonance/) is a keyboard instrument that turns each note into light and motion.
- [Pixel Kitten · Meow to the Beat](pixel-kitten/) explores attention and practice through rhythm.
