# Orbital Resonance

A keyboard-controlled audiovisual instrument by Murphy Nile, part of the **AI-Assisted Mini Games** series.

## Play

Download the repository and keep the four project files together. Open [index.html](index.html) in a desktop browser with WebGL and Web Audio. Select **Enter / Enable Audio** or press a playable key.

Use **A S D F G H J K L ; W E** to play twelve asteroids. You can play several notes together or click the large asteroids and on-screen keys. Drag to orbit and scroll to zoom.

## Research practice

What can a single keystroke make perceptible? Each key triggers a note, a flash, and movement in the same asteroid. The pitches share a D-minor pentatonic scale, so players can build layers of sound with a few keys while seeing where each voice comes from.

Like *Hum Doom*, this study uses sound to make a system perceptible. Here, the player supplies the event and can hear and see its effect together.

The geometry and sound are generated in the browser. No installation or network connection is required after download.
